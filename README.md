# 🏠 Digital Home - Социальная сеть (60% завершено к 26.04.26)

## ✅ Что реализовано

### 1️⃣ Хеширование паролей с bcryptjs
- ✅ Установлен `bcryptjs@^2.4.3`
- ✅ Реализованы методы хеширования в `User` модели
- ✅ Метод `matchPassword()` для проверки пароля
- ✅ Автоматическое хеширование при сохранении пользователя
- ✅ Использование генерации соли (10 раундов)

### 2️⃣ Основная логика приложения

#### Backend (Node.js + Express)
- ✅ REST API на порту 5000
- ✅ Авторизация:
  - POST `/api/auth/register` - регистрация с хешированием паролей
  - POST `/api/auth/login` - вход с проверкой пароля
- ✅ Посты:
  - POST `/api/posts` - создание нового поста
  - GET `/api/posts` - получить все посты
  - GET `/api/posts/:id` - получить конкретный пост
  - PUT `/api/posts/:id` - обновить пост
  - DELETE `/api/posts/:id` - удалить пост
  - POST `/api/posts/:id/like` - лайкнуть пост
- ✅ Mock-режим (встроенное хранилище в памяти) при недоступности MongoDB

#### Frontend (React + Vite)
- ✅ Интерфейс авторизации (LoginForm)
- ✅ Главная страница с социальной лентой (MainPage)
- ✅ Создание постов (PostCreator) - интегрировано с API
- ✅ Список постов (PostList) - загружает с сервера
- ✅ Карточки постов (PostCard) - лайки и информация об авторе
- ✅ Меню управления (TopMenu, Sidebar)
- ✅ State управление с Zustand

#### Database
- ✅ Модель User с хешированием паролей
- ✅ Модель Post с привязкой к автору
- ✅ Mock-store для работы без MongoDB

## 🔑 Ключевые особенности

1. **Безопасность**
   - Пароли хешируются с bcryptjs (10 раундов соли)
   - Валидация на фронте и бэке
   - CORS включен

2. **Отказоустойчивость**
   - Mock-режим при недоступности MongoDB
   - Все данные сохраняются в памяти
   - Полная функциональность без БД

3. **Архитектура**
   - Разделение на frontend и backend
   - REST API для всех операций
   - Zustand для управления состоянием
   - Модульная структура компонентов
